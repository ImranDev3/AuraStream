## 📖 Overview
**AuraStream AI** is a high-performance, open-source music streaming application designed to provide a premium Spotify-like experience using YouTube as a backend. Built for the community, it offers background playback, AI-driven UI transitions, and zero advertisements.

---

## ✨ Key Features
- **🎥 YouTube Integration:** Stream any audio directly from the world's largest video library.
- **📱 Background Playback:** Keep the music alive even when your screen is off.
- **🌑 Dark Aura UI:** A stunning Neon-Glassmorphism interface designed for night-long listening.
- **🔐 Google Login:** Securely sync your library across devices with Firebase.
- **🚀 Ultra-Fast Search:** Real-time search indexing for millions of tracks.
- **🎵 Colorful Animations:** Smooth 60FPS transitions powered by Framer Motion.

---

## 🛠 Tech Stack
- **Frontend:** React 18 + Vite 8
- **Animations:** Framer Motion
- **Icons:** Lucide-React
- **Auth/Database:** Firebase
- **API:** YouTube Data API v3

## 🚀 Installation & Setup

1. **Clone the Repo:**
   ```bash
   git clone https://github.com/ImranDev3/AuraStream.git
   ```
2. **Install Dependencies:**
   ```bash
   npm install
   ```
3. **Run Dev Server:**
   ```bash
   npm run dev
   ```
